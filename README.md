# 🚀 Concept Fitness - Digital Flagship Experience

Este é um projeto de alta performance desenvolvido com **Next.js 14**, **Tailwind CSS**, **Framer Motion** e **GSAP**.

## 🛠️ Como hospedar no Vercel (Passo a Passo para iniciantes)

Você não precisa rodar o site no seu computador. O Vercel fará tudo para você:

1. **Crie uma conta no GitHub** (github.com) se ainda não tiver.
2. **Crie um novo Repositório** chamado `concept-fitness`.
3. **Suba os arquivos:**
   - Você pode usar o [GitHub Desktop](https://desktop.github.com/) para subir a pasta `concept-fitness` para o seu repositório.
   - Ou, se preferir, arraste a pasta para o site do GitHub.
4. **Conecte ao Vercel:**
   - Vá em [vercel.com](https://vercel.com) e faça login com seu GitHub.
   - Clique em **"Add New"** $\to$ **"Project"**.
   - Importe o repositório `concept-fitness`.
   - Clique em **"Deploy"**.

**Pronto!** O Vercel vai te dar um link (ex: `concept-fitness.vercel.app`) e o site estará no Google para qualquer pessoa acessar.

## 📂 Estrutura do Projeto
- `src/app`: Páginas e Rotas.
- `src/components/sections`: As seções da narrativa cinematográfica.
- `public`: Onde ficam o vídeo do Hero e as fotos da academia.

## 🎨 Design System
- **Cores:** Obsidian Deep (#050505), Carbon (#1A1A1A), White (#FFFFFF).
- **Animações:** Lenis Smooth Scroll + GSAP + Framer Motion.
